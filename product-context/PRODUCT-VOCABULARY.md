# Product Vocabulary

Use one stable language system across navigation, screens, email, Storybook,
fixtures, and design discussion.

| Concept | Preferred language | Avoid |
|---|---|---|
| User-created product object | Idea | invention record, submission object |
| Formal completed content | Invention disclosure | form payload |
| Primary start action | Submit an idea | create record, new disclosure form |
| Client reviewer | Workspace Admin | IHC, counsel admin, committee role |
| Photon delivery owner | Case Owner | OC user, delivery attorney in client UI |
| Firm administrator | Photon Admin | superadmin in user-facing text |
| Evaluation number | Patentability score (0–10) | novelty score, patentability probability, success chance |
| Score band | Highly novel · Moderately novel · Marginally novel · Closely matched · Not evaluated | likely to be granted, pass/fail |
| In-draft live reading | Patentability signal | pre-score, preview score |
| Existing technology evidence | Prior art | prior arts |
| Review success action | Send to Photon Legal | approve idea (without consequence), approve for filing |
| Confirmation title | Send to Photon Legal for filing? | Are you sure? |
| Confirmation action | Send to Photon Legal | Continue, Approve & send |
| Post-approval state | Sent to Photon Legal | send to OC |
| Inventor-to-review action | Submit for review | send to committee |
| Optional analysis action | Evaluate idea | Evaluate submission (current draft label, converges here), test, calculate patentability |
| Revision action | Request changes | send back (without explanation) |
| Patent request area | Actions | docketing |

## Score language

- Score is always 0–10, shown as `7.4 / 10`, with one band label.
- Bands: ≥8 Highly novel, ≥6 Moderately novel, ≥4 Marginally novel,
  <4 Closely matched, none Not evaluated.
- No cutoff is communicated; a band is a description, not a decision.
- Every score can be submitted.
- Explain a score using evidence and differentiators, not probability claims.
- Avoid `highly likely`, `most patentable`, `objectively novel`, or guarantees.

## Copy test

Important actions should name the object and consequence. Avoid generic labels
such as `Continue`, `Yes`, `Proceed`, `Submit`, or `Confirm` when a more precise
label is possible.
