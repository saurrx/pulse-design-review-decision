# Adopted External Lessons

## Linear

- Design is fit between form and context, not generation of output.
- Quality is a business strategy and a source of advocacy.
- Dense products need strong attention hierarchy.
- Secondary navigation should not compete with the user's work.
- AI accelerates exploration and execution; human judgment still selects.

Pulse application: start with persona/job, lead with the task, and polish the
whole experience rather than decorating isolated screens.

## Apple

- Purpose precedes interface.
- Agency and recovery make users comfortable exploring.
- Responsibility and privacy build trust.
- Familiar patterns reduce learning cost.
- Simplicity means exactly enough, not merely less.
- Delight is the result of accumulated care rather than added decoration.

Pulse application: create confidence, preserve work, clarify consequence, and
use motion as feedback.

## Vercel

- Code records what shipped, not why.
- Product judgment must be made legible to agents.
- Mechanical quality rules should be enforced automatically.
- Every reachable state matters.
- Rendered verification is required.

Pulse application: keep this context beside the design work and use the
scorecard, surface briefs, Storybook states, and browser review.

## Figma/AI workflow

- The source of truth is the system of research, product decisions, design,
  content, and code.
- Canvas is useful for divergent exploration; code is useful for focused proof.
- Design-system structure and meaningful naming improve agent output.

Pulse application: one agent may work across phases, but human direction must
choose the identity and evaluate tradeoffs.

## Google expressive design

- Strategic size, contrast, color, and containment can help users locate key
  actions faster.
- Emotional expression cannot compensate for unclear functionality.
- Expression must fit the audience.

Pulse application: use Photon color and meaningful emphasis to guide action,
not to make the product louder.
