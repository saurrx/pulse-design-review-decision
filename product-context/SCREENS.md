# V0 Screen Inventory

## Shared public/account

- Login
- Domain-gated signup
- Invitation acceptance
- Forgot password
- Reset password
- SSO return/failure
- Access denied/session expired
- Profile and password

## Inventor navigation

```text
Home · Ideas · Patents · Profile
```

Screens:

- Inventor Home
- Start an Idea
- Invention Disclosure Workspace
- Evaluation Result
- My Ideas
- Idea Detail and Status
- Patent Portfolio
- Patent Detail (read-only, no dates)
- Profile

## Workspace Admin navigation

```text
Home · Ideas [pending badge] · Patents · Actions · Workspace · Profile
```

Screens:

- Workspace Admin Dashboard
- Idea Review Queue
- Review Decision
- Submit an Idea / Submit on Behalf
- Patent Portfolio
- Patent Detail with contextual dates
- Actions with contextual dates
- Workspace Organization
- People and Invitations
- Business Scope
- Profile

There is no separate Due Dates destination.

## Cross-screen rules

- Only pending Workspace Admin reviews receive a navigation badge.
- Actions receive contextual alerts but no navigation badge.
- There is no notification center or bell.
- The patent world map appears on every V0 dashboard, below the persona's work; it never leads.
- Jurisdiction counts and filtering also belong in Patent Portfolio.
- Every dashboard begins with work or momentum relevant to that persona.
- Internal IDs never appear.
