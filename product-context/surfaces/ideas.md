# Ideas List

## Variants

Inventor, Workspace Admin, Case Owner, Photon Admin.

## Job by persona

- Inventor: find own drafts/submissions and their next step.
- Workspace Admin: clear pending reviews.
- Case Owner: find approved ideas from assigned clients.
- Photon Admin: oversee ideas sent to Photon across clients.

## Hierarchy rules

- Columns and default sort change with the persona's job.
- Workspace Admin pending review sorts oldest first and shows days waiting.
- Inventor emphasizes status, last update, score, and next action.
- Photon views include client and ownership context.
- Row opens the record directly; avoid an unnecessary preview step.

## Navigation badge

Only Workspace Admin pending-review count receives a badge.

## States

Empty, drafts only, mixed statuses, long titles, large queue, filtered empty,
loading, error, requested changes, evaluation running.
