# Clients and Onboarding

## Personas

Case Owner and Photon Admin.

## Job

Find an assigned/all client, understand its setup, and complete onboarding.

## Client list

- Search
- Existing/potential status where V0 requires it
- Assigned Case Owner
- Workspace setup state
- Patent count
- Recent activity or attention indicator

Avoid large decorative cards when a compact, scannable representation supports
the work better.

## Client workspace

- Identity and allowed domain
- Workspace Admins and inventor participation
- Idea/review summary
- Portfolio summary
- Data import history
- Upcoming Actions/dates
- Case Owner assignments
- Enter client view

## Onboarding flow

```text
Create organization
→ Configure allowed domain
→ Assign Case Owner
→ Invite first Workspace Admin
→ Set up inventor invitation method
→ Import initial patent spreadsheet
→ Confirm readiness
```

## States

Potential client, new client, no admin, no inventors, no portfolio, import in
progress, import duplicates/errors, ready, disabled/offboarded, access request.
