# Workspace Admin Dashboard

## Job

Clear the review queue and understand whether the invention program is moving.

## Business outcome

Reduce submission-to-decision time and increase ideas sent to Photon.

## Hierarchy (as built — this is the reference screen)

1. Stat strip: awaiting review (oldest age), deadlines in 30 days, total
   patents, granted, pending patents — each with one next-step line
2. Patents worldwide: the world map with jurisdiction count and zoom
3. Top inventors this quarter (ideas / patents toggle)
4. Review inventor ideas: title, inventor, score, submitted age, with
   **Open queue** as the primary action
5. Idea pipeline: submitted, review pending, sent to Photon Legal, filed, granted

## Rules

- Pending reviews occupy prime space before aggregate metrics.
- Pending sorts oldest first.
- Clearly distinguish workspace pipeline from company patent portfolio.
- The world map and Top inventors are authorised here and only here.
- No cost analytics in V0.
- This screen is the visual reference for every other V0 screen; change it
  only to fix a defect, and record the change.
- Ideas navigation carries pending-review count.

## States

No pending reviews, one urgent review, large aging queue, no recent ideas,
healthy growth, declining submissions, data unavailable.
