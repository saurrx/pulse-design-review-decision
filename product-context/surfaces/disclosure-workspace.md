# Invention Disclosure Workspace

## Job

Complete a credible invention disclosure without needing patent expertise.

## Business outcome

Increase draft completion and completed-to-submitted conversion.

## Primary action

**Submit for review** when required information is complete.

## Secondary action

**Evaluate idea** — visibly optional and never a gate.

## Structure

- Clear completion overview
- Sections matching the invention narrative
- Prefilled answers distinguished without visual noise
- Gaps and unsupported fields
- Copilot improvement/follow-up help in context
- Co-inventors
- Source material
- Autosave/last-saved state
- Optional evaluation card

## Draft model

One canonical active disclosure with version history. Submission freezes the
reviewed version. Request changes reopens the same disclosure and creates a new
revision in history.

## Rules

- Prefill only when source material supports the answer.
- Never invent technical facts.
- Crucial human-conception/novelty content cannot be silently AI-authored.
- Show AI-drafted/edited/human provenance where required.
- Do not warn or nag when the inventor submits without evaluation.
- Preserve work through errors and navigation.

## States

Empty, partially prefilled, unsupported gaps, saving, saved, offline, conflict,
complete, evaluation running/result/stale, requested changes, resubmission.
